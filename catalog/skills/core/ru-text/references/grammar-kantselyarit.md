# Грамматика, пунктуация, канцелярит, кальки

Ошибки правим уверенно, стиль — осторожно. Цитаты, прямую речь и тексты клиентов не трогаем.
Порядок: грамматика и орфография → бесспорная пунктуация (спорное — автору) → канцелярит и кальки по жанру
(в договоре и ТЗ — только аудит) → перечитать свои правки на согласование.

## 1. Частые ошибки

| Ошибка | Правильно |
|---|---|
| согласно договора, вопреки плана, благодаря поддержки | согласно договору, вопреки плану, благодаря поддержке |
| по приезду, по окончанию работ | по приезде, по окончании работ |
| оплатить за доставку | оплатить доставку / заплатить за доставку |
| в течении недели, что бы успеть, так же (= тоже) | в течение недели, чтобы успеть, также |
| иметь ввиду, не смотря на, в следствии | иметь в виду, несмотря на, вследствие |
| преимущество над конкурентами, заведующий отдела | преимущество перед конкурентами, заведующий отделом |
| организовать и руководить работой | организовать работу и руководить ею |
| ложить, обоим сторонам | класть, обеим сторонам |
| более лучший, свободная вакансия | лучший, вакансия |
| 2-ая, 10-ом | 2-я, 10-м |

**Висячий деепричастный оборот:** «Открыв файл, появилась ошибка» → «Открыв файл, мы увидели ошибку».
**Согласование с числом:** «21 заказ», «22 заказа», «25 заказов» — проверять после замен.

## 2. Пунктуация

- Сложный союз («потому что», «так как») — запятая перед всем союзом; разделять только ради акцента.
- **Не вводные** (без запятых): как будто, поэтому, якобы, вряд ли, причём, всё-таки, наверняка.
- **Вводные** (с запятыми): конечно, кажется, во-первых, к сожалению, например (внутри фразы), впрочем.
- «Однако» в начале фразы в значении «но» — без запятой. Обращение — всегда с запятыми.
- Двоеточие — перед пояснением или перечислением; тире — перед следствием, при пропуске глагола, перед обобщающим словом.
- Обособленное определение после определяемого слова — с запятыми: «Отчёт, собранный за ночь, ушёл клиенту».

Авторская пунктуация и ритм — оставить и отметить «на решение автора».

## 3. Канцелярит

Признаки (идеи по книге Норы Галь «Слово живое и мёртвое»; примеры свои):

| Маркер | Было | Стало |
|---|---|---|
| Существительное вместо глагола | осуществить проверку | проверить |
| Пустой глагол + отглагольное | провести согласование, оказать помощь | согласовать, помочь |
| Цепочка родительных | вопрос повышения качества обработки заявок | как быстрее отвечать на заявки |
| «Является», «представляет собой» | Компания является подрядчиком | Компания — подрядчик |
| «Данный», «в целях», «в рамках» | в целях повышения узнаваемости | чтобы бренд узнавали |
| Пассив, прячущий деятеля | было принято решение о переносе | мы решили перенести |
| Словесная алгебра | момент с оплатой | оплата |
| Мнимая учёность | функционирует, локализовать проблему | работает, найти проблему |
| Модальная муть | следует отметить, представляется возможным | — / можно |

**Лечение:** найти действие и деятеля — кто что делает. Тест «на камеру»: можно ли снять написанное?
«Осуществление контроля качества» не снять, «проверяем каждую партию» — можно. Тест «за чаем»: сказал бы так коллеге?

**Норма жанра:** договор, ТЗ, акт, регламент, ответ ведомству — правим только ошибки и явную тавтологию.
Термины («проведение документа») — не канцелярит; «осуществить проведение» — канцелярит.

## 4. Кальки

Признак переведённого текста — английский синтаксис русскими словами.

| Калька | По-русски |
|---|---|
| мог отчётливо видеть | видел |
| был первым, кто заметил | первым заметил |
| адресовать проблему | решить проблему, заняться |
| доставить ценность | помочь, дать пользу |
| на ежедневной основе | каждый день |
| делает возможным | позволяет |
| играет ключевую роль | назвать, что именно делает |
| не может быть отменено | нельзя отменить |
| поднял свою руку | поднял руку |
| релевантный, имплементировать | подходящий, внедрить (вне жаргонной среды) |

- Идиомы переводим смыслом. Смысловое ударение русской фразы — в конце.
- «Он/она/это» в начале каждой фразы, три «который» в предложении — перестроить.
- Жаргон среды — не калька, если читатель из среды (`false-positives.md`).

## 5. Значение, сочетаемость, повторы

- Паронимы: одеть/надеть, представить/предоставить, эффектный/эффективный.
- Вывихнутые идиомы: «играть значение» (играть роль / иметь значение), «уделять внимание к».
- Разностилица без умысла: канцелярит рядом с жаргоном.
- Однокоренные рядом — заменить одно, если это не приём. Повтор термина — НЕ тавтология.
- Плеоназм: «главный приоритет», «период времени», «впервые дебютировал», «прейскурант цен».
