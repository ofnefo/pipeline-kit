# Нормализация: всё, что движок может прочитать неправильно

Правило одно: в TTS-файле нет цифр, сокращений, символов и латиницы без решения. Qwen3-TTS не
нормализует текст вообще, другие движки делают это по-своему (один популярный русский движок, по
наблюдениям его же документации, молча выбрасывал цифры: «Кабинет 405» звучало как «Кабинет»). Пишем
словами сами, с правильным падежом.

## Числа

- Количественные согласуются с существительным: «21 участник» → «двадцать один участник»,
  «22 участника» → «двадцать два участника», «25 участников» → «двадцать пять участников».
- Порядковые: склоняется только последнее слово: «в 152-м зале» → «в сто пятьдесят втором зале».
- После предлогов — нужный падеж: «от 5 до 7 минут» → «от пяти до семи минут»; «около 300 гостей» →
  «около трёхсот гостей». Падеж проверять в каждом месте, а не копировать форму.
- Диапазон «5–7» вслух лучше как «от пяти до семи», а не «пять-семь».
- Дроби: «2,5 млн» → «два с половиной миллиона»; «0,8» → «ноль целых восемь десятых» (или переписать фразу).
- Большие круглые числа можно округлять, если это не цифра отчёта: «1 487 гостей» → «почти полторы тысячи гостей» — только с согласия автора текста.
- Римские: «XXI век» → «двадцать первый век»; «в XXI веке» → «в двадцать первом веке».
- Номер в названии не склоняется: «Сезон-2» → «Сезон-два».
- Слова с числом внутри: «3D» → «три-дэ», «5-летний» → «пятилетний», «10-минутный» → «десятиминутный».

## Даты и годы

- «04.10.2026» → «четвёртое октября две тысячи двадцать шестого года» (в начале фразы — именительный
  «четвёртое октября», после «к», «до», «с» — нужный падеж: «до четвёртого октября»).
- Год: «в 2026 году» → «в две тысячи двадцать шестом году»; «2026 год» → «две тысячи двадцать шестой год».
- «г.» → «года/году/год» по падежу. Десятилетия: «1990-е» → «девяностые», «в 2000-х» → «в двухтысячных».
- Дни недели и месяцы — полностью, без сокращений «пн», «окт.».
- Если год очевиден из контекста мероприятия — его можно не читать вовсе.

## Время

- Официальное объявление: «в 18:30» → «в восемнадцать тридцать»; «в 9:05» → «в девять ноль пять».
- Разговорная подводка: «в 18:30» → «в половине седьмого вечера». Выбрать один вид на весь сценарий
  и держать его; в объявлениях — тот же вид, что напечатан в программе.
- «10:00» → «десять ноль-ноль» или «десять утра»; «с 10:00 до 18:00» → «с десяти утра до шести вечера».
- Длительность: «1,5 ч» → «полтора часа»; «45 мин» → «сорок пять минут».

## Деньги и проценты

- «1 500 ₽» → «тысяча пятьсот рублей» или «полторы тысячи рублей»; «21 ₽» → «двадцать один рубль».
- «$1200» → «тысяча двести долларов»; «€50» → «пятьдесят евро».
- «25%» → «двадцать пять процентов»; «21%» → «двадцать один процент»; «3%» → «три процента».
- «+15%» → «плюс пятнадцать процентов» или «на пятнадцать процентов больше».

## Телефоны, адреса, сайты, почта

- Телефон группами, как его диктуют: «+7 495 123-45-67» → «плюс семь, четыреста девяносто пять,
  сто двадцать три, сорок пять, шестьдесят семь». Запятые дают паузы между группами.
- Сначала спросить себя: нужен ли телефон в озвучке? Часто лучше «номер — на экране».
- Адрес: «ул. Садовая, д. 10, стр. 2» → «улица Садовая, дом десять, строение два».
- Сайт: «site.ru» → «сайт точка ру», латиница — кириллицей так, как её произносят. «@» → «собака»,
  «/» → «слэш». Длинные ссылки в озвучку не ставить.

## Залы, этажи, номера

- «Зал 3» → «третий зал» или «зал номер три» — как названо на табличках площадки. Одинаково во всём сценарии.
- «Зал B» → «зал Бэ» (или «зал Би», если на площадке говорят по-английски) — уточнить у организатора.
- «2 этаж» → «второй этаж»; «на 2-м этаже» → «на втором этаже».
- «№ 5» → «номер пять»; «стенд A12» → «стенд А-двенадцать».

## Аббревиатуры

- Читается словом, если её можно произнести слогами: ВУЗ → «вуз», МИД → «мид», ГОСТ → «гост», ООН → «оон».
- Читается по буквам, если согласные идут подряд: ФСБ → «эф-эс-бэ», ГИБДД → «гэ-и-бэ-дэ-дэ»,
  МГУ → «эм-гэ-у». В TTS-файле писать уже буквами через дефис.
- Названия русских букв: бэ, вэ, гэ, дэ, жэ, зэ, ка, эл, эм, эн, пэ, эр, эс, тэ, эф, ха, цэ, че, ша.
- Есть устойчивые исключения (США → «сэ-шэ-а», ЦСКА → «цэ-эс-ка»): проверять по тому, как говорят люди.
- Латинские: IT → «ай-ти», PR → «пиар», SMM → «эс-эм-эм», VR → «ви-ар», B2B → «би-ту-би», CEO → «си-и-о»
  (или «генеральный директор» — по-русски часто лучше).
- Сокращения слов раскрыть полностью: «т. е.» → «то есть», «и т. д.» → «и так далее», «млн» → «миллион(ов)»,
  «тыс.» → «тысяч», «руб.» → «рублей», «им.» → «имени».
- Кавычки вокруг названия в TTS-файле убрать, если они не нужны для интонации.

## Иностранные имена, бренды, латиница

- Имя человека — так, как он сам себя называет. Источник: организатор, сам спикер, его выступления.
  Не знаем — вопрос в список, сегмент помечаем как блокирующий.
- В TTS-файле латиницу переписать кириллицей: «Microsoft» → «Майкрософт», «Nvidia» → «Энвидиа».
  Как Qwen3-TTS читает латиницу внутри русской фразы — **не проверено**; кириллица надёжнее.
- Бренд читаем так, как он называет себя сам в рекламе и на сайте; русские бренды — по их же написанию.
- Двойные фамилии и отчества — целиком в первый раз, дальше можно по имени, если так принято на мероприятии.
- Ударение в имени — как в именительном падеже, во всех падежах («Мо́ксон — Мо́ксона», а не «Мокс+она»);
  если это не нарушает норму для известных русских фамилий.

## Символы и знаки

| Знак | Вслух |
|---|---|
| % | процент/процента/процентов |
| № | номер |
| & | и |
| + | плюс (в числах), «и» (в названиях: «Арт+Тех» → «Арт и Тех» — уточнить) |
| / | «или», «и», «на» или дефис — по смыслу: «50/50» → «пятьдесят на пятьдесят»; «км/ч» → «километров в час» |
| ° | градус/градуса/градусов |
| × | на («3×4 метра» → «три на четыре метра») |
| — | тире остаётся: это пауза и интонация |

## Проверка после нормализации

- Поиск по TTS-файлу: цифры `[0-9]`, латиница `[A-Za-z]`, символы `%№&@/+°×`, точки сокращений — должно быть ноль
  (кроме осознанных случаев, записанных в словарь). Для кириллических регулярных выражений надёжнее Python, чем `grep -E`.
- Каждое число — с падежом, проверенным в своей фразе.
- После замены цифр словами ударения в числительных проверить отдельно: «четырёхсот», «восьмидесяти»,
  «шестидесяти», «пятью» — частая зона ошибок любых автоматических расстановщиков.
