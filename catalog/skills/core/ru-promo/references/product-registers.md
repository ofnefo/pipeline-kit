# Регистры продуктового текста

Основа — Dankosik/yandex-tone-of-voice-skill (MIT, © 2026 Dankosik). **Это независимая
реконструкция по публичным продуктовым текстам, а не официальное руководство Яндекса.**
Используем как удобную систему регистров, не как «стандарт Яндекса». Пересказано и сокращено.

## Регистры по типу продукта

| Регистр | Задача текста | Тон | Пример глаголов |
|---|---|---|---|
| Массовый | бытовая польза | просто, дружелюбно | покажет, подскажет, не придётся |
| On-demand / городской | скорость и доступность | энергично | заказать, отправить, забронировать |
| Развлекательный, события | предвкушение | теплее, образнее | приходите, увидите, для вас |
| Образовательный | снять страх, показать путь | поддерживающе, честно | начнёте, освоите, закрепите |
| Малый бизнес | освободить время | практично, без снобизма | достаточно указать, пока вы заняты… |
| B2B | сравнить и внедрить | предметно: процесс, кейс, результат | запустить, настроить, интегрировать |
| Технический / Developer | контроль и доверие | компактно, по стандартам | подключить, документация, API |
| Корпоративный | принципы и ответственность | открыто, от «мы» | мы считаем, для нас важно |

Один блок — один регистр: игривый заголовок с канцелярским пояснением не работает.

Типичные сочетания: ивент-агентство — B2B + «события» в визуальных блоках; Telegram-бот для
малого бизнеса — малый бизнес / массовый; SaaS и платформы для организаторов — B2B / технический.

## Грамматика по умолчанию

- «Вы» со строчной, если бриф не задаёт иначе.
- Настоящее время — постоянная возможность; будущее — обоснованный результат; повелительное — призыв.
- Действие называет того, кто его делает: «сервис сравнит варианты», а не «осуществляется сравнение».
- Глагол вместо отглагольного существительного: «анализирует», а не «проводит анализ».
- «Ё», кавычки «ёлочки», заголовки без точки, кнопки обычно в инфинитиве.
- Не нормализовать названия, URL, код, плейсхолдеры, точные цитаты.

## Слова с проверкой

«Просто», «быстро», «автоматически», «в один клик», «не придётся» — только если сложность
реально исчезла. «Лучший, самый, уникальный, инновационный, мгновенно, бесплатно, без ограничений,
абсолютно безопасно» — не запрет, а сигнал проверить основание и добавить условие.

## Модели фраз (по смыслу, не по очереди)

- `[Продукт] [делает работу], а вы [получаете результат]`.
- `Достаточно [простое действие] — [что сделает продукт]`.
- `[Неприятное действие] не придётся: [известная функция]`.
- `[Набор] — в одном [окне / приложении / договоре]`.
- `Для [роли]: [возможность], чтобы [результат]`.

Модель фразы не доказывает функцию, цену или скорость — факты всё равно из брифа.

## Ответственный слой

Когда обещание касается денег, права, здоровья, безопасности данных, ошибок или ИИ:
- рядом с обещанием — существенное условие (срок, комиссия, «до», ограничения);
- «0 ₽ первый платёж» ≠ бесплатно; «до 40%» ≠ 40% каждому;
- не выдумывать сертификаты, шифрование, хранение «в России», аудит, если этого нет в брифе;
- «ИИ помогает» — назвать конкретную помощь и роль человека, без «никогда не ошибается»;
- сообщения об ошибке: что не получилось и что сделать; без шуток при риске потери денег или данных.

Это редакторские границы, а не юридическая проверка.
