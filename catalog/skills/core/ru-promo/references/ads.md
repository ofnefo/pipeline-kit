# Объявления: углы, варианты, лимиты площадок

Метод углов и пакетной генерации — пересказ `skills/ad-creative` из coreyhaines31/marketingskills
(MIT, © 2025 Corey Haines). Лимиты — из официальных справок площадок, **проверено 2026-10-04**.
Лимиты меняются: перед запуском кампании сверить по ссылке. Чего нет на официальной странице —
помечено «не проверено».

## Процесс

1. Бриф: продукт/услуга, аудитория, посадочная страница (её первый экран), действие, факты
   (цена «от», сроки, гео, условия), запреты.
2. Выбрать 3–5 углов из списка ниже под эту аудиторию.
3. На каждый угол — 2–3 варианта. Каждый вариант полный: все обязательные поля площадки.
4. Посчитать длину каждого поля (символы с пробелами и знаками) и показать в таблице.
5. Проверить: обещание объявления совпадает с первым экраном посадочной; нет фактов вне брифа;
   нет превосходных степеней без основания («лучший», «№1» требуют подтверждения).
6. Отдать таблицей; запуск кампании — только владелец кампании или агент по его прямой команде.

## Углы

| Угол | Суть | Пример заготовки (плейсхолдеры) |
|---|---|---|
| Боль | ситуация, которую человек хочет закончить | «Форум через [N] недель, а площадки нет?» |
| Результат | что будет после | «Корпоратив на [N] человек под ключ за [срок]» |
| Доказательство | цифра, кейс, клиенты (только реальные) | «[N] мероприятий для [тип клиентов] с [год]» |
| Любопытство | недосказанность без кликбейта | «Что входит в смету выездного форума» |
| Сравнение | против привычной альтернативы | «Регистрация участников без Excel и ручных списков» |
| Срочность | реальный дедлайн, а не выдуманный | «Даты на [месяц] ещё есть» — только если правда |
| Идентичность | «для таких, как вы» | «Для HR, которым нужен выезд без хаоса» |
| Против течения | спорный, но честный тезис | только с фактом в основе |

## Яндекс Директ — ЕПК, текстово-графическое объявление

Источник: https://yandex.ru/support/direct/ru/moderation/technical-restrictions (проверено 2026-10-04).

| Поле | Лимит |
|---|---|
| Заголовок | до 56 символов с пробелами и знаками; слово до 22 символов |
| Дополнительный заголовок | до 30 символов, до 15 знаков препинания; слово до 22 |
| Текст | до 81 символа, до 15 знаков препинания; слово до 23 |
| Отображаемая ссылка | до 20 символов (без домена) |
| Ссылка | до 1024 символов |
| Уточнения | каждое до 25 символов; суммарно до 132 (десктоп) и до 76 (мобильные) |
| Быстрые ссылки | заголовок до 30, описание до 60 |
| Изображения | от 450 px по стороне, JPG/PNG/GIF, до 10 МБ |
| Видео | 5–60 с, до 100 МБ, от 360p |

Быстрые ссылки: https://yandex.ru/support/direct/ru/efficiency/quick-links (проверено 2026-10-04) —
до восьми быстрых ссылок; текст до 30, описание до 60.
**Не проверено:** суммарный лимит 66 символов на заголовки быстрых ссылок (встречается в
сторонних источниках, на официальной странице ЕПК не найден).
Комбинаторные объявления ЕПК и продвижение приложений имеют свои ограничения — смотреть
соответствующие разделы той же страницы, здесь не переписаны.

Практика для Директа:
- Ключевая фраза или её смысл — в заголовке; география и цена «от» — в тексте или уточнениях.
- Дополнительный заголовок может не показываться — смысл не должен на нём держаться.
- Быстрые ссылки ведут на разные реальные разделы сайта (кейсы, цены, контакты, FAQ).

## VK Реклама

Источник: https://ads.vk.ru/help/features/formats («Форматы VK Рекламы», проверено 2026-10-04;
ads.vk.com в момент проверки не открылся, использовано зеркало справки ads.vk.ru).

| Формат / поле | Лимит |
|---|---|
| Универсальное объявление для сайта: заголовок | до 40 символов |
| Короткое описание | до 90 символов |
| Длинное описание | для сайтов — до 16 384 символов по официальной странице; сторонние источники пишут 2000 — расхождение, перед запуском сверить в кабинете |
| Карусель для сайтов: заголовок слайда | до 40 символов |
| Карусель: описание слайда | до 50 символов |
| Текст кнопки (выбор из списка или свой) | **не проверено** |
| Правила по эмодзи, заглавным буквам | **не проверено** |

Практика для VK: заголовок читается без описания; короткое описание — суть оффера и действие;
карусель — один слайд = один сценарий или один кейс.

## Таблица выдачи

```
| # | Угол | Заголовок (симв.) | Доп. заголовок (симв.) | Текст (симв.) | Быстрые ссылки | Примечание |
```
Для VK: Заголовок · Короткое описание · Длинное описание (если нужно) · Кнопка.

Считать символы скриптом или вручную с пробелами и знаками; варианты на грани лимита помечать.

## Маркировка

С 01.09.2022 интернет-реклама в РФ маркируется: пометка «Реклама», указание рекламодателя и токен
ERID; сведения передаются в ЕРИР через ОРД (ФЗ «О рекламе», ст. 18.1). Как именно получить токен
для конкретной кампании или посева — решает рекламодатель при запуске.
