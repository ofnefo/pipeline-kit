# Modeling and scene organization

Use real units and clean transforms. Organize collections by venue, project geometry, equipment, graphics placeholders, lights, cameras, and references. Name objects for function, not appearance.

Prefer reusable modular assets, instances, arrays, mirrors, and non-destructive modifiers when they preserve editability. Apply modifiers only for a documented export or downstream requirement. A panel has thickness; a tall object needs a real support concept; an opening remains an opening.

Use bevel only for a physical edge radius or correct highlight. Avoid universal bevels, hidden duplicate meshes, non-manifold production solids, accidental negative scale, and decorative geometry that hides unresolved dimensions.

For imported meshes, inspect units, orientation, normals, topology, material slots, bounding box, and origin before placement. Keep source objects or links available for traceability.
