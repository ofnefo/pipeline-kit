# Optimization, packaging, and export

Optimize against the destination: interactive review, render, animation, game engine, web, fabrication reference, or archive.

- remove only proven duplicates and unused temporary data;
- instance repeated assets and control subdivision/texture size by camera need;
- preserve a high-quality source before decimation, baking, or destructive cleanup;
- verify linked libraries, fonts, textures, caches, color management, and external paths;
- use relative paths or package approved dependencies for handoff.

For GLB/FBX/USD/OBJ, validate units, axis, transforms, hierarchy, materials, texture paths, normals, UVs, animation ranges, and object names in a fresh import. STL is a mesh exchange, not an editable dimensional master. Use STEP through `$cad-production` when exact solids or parametric exchange matter.
