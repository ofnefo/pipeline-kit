# Layouts and artboards

Start with physical dimensions, scale, orientation, bleed/wrap, safe area, seams, viewing distance, obstructions, and deliverable variants. Build shared grids, spacing tokens, logo zones, type hierarchy, baseline behavior, and image treatment before duplicating artboards.

Use one artboard per controlled variant and stable names such as `<ZONE>_<SIZE>_<VERSION>`. Keep artwork within the intended artboard and separate common elements from variant content. Review a series as a strip, not only one artboard at a time.

Keep hierarchy to what the viewing distance supports. Test a small preview, grayscale, normal proof, and installed adjacency. Exact copy, logos, QR codes, legal text, and wayfinding remain deterministic.
