# Spatial style framework

Use this only when the workspace handbook is unavailable.

## Independent layers

- `discipline`: exhibition, show, wedding, interior, retail, museum, hybrid;
- `typology`: physical and functional organization;
- `style`: visual and material language;
- `mechanic`: how a person participates or how the environment changes;
- `build_system`: one-off, rental, modular, circular kit, permanent;
- `delivery_level`: hero, buildable, value_engineered;
- `creative_level`: C0 restrained, C1 distinctive, C2 experimental.
